# NTRU / 格陷门 / DKG / 门限签名专项审查

此文件只在项目 `RESEARCH_PROFILE.json` 含 `ntru_lattice` 时启用。

1. 固定具体代数环、模数、维度、NTRU 方程方向与既定符号；核对从低维到高维的 Field Norm、扩展 GCD、整数回升、Babai/GSO 相关约束。
2. 区分验证端低位宽同余判定与构造端精确短补全。给出整数范围和每层实际最大位宽，不得由最终模验证代替生成证明。
3. 任何下降/回升重参数化必须检查自由度和代表元短性；代数正确、同余正确和短性正确分别证明。
4. 检查 NTRU 密钥分布与标准算法兼容性、秘密共享/KeyExpand 辅助参数、分布式采样、联合拒绝/中止泄漏。
5. 门限层必须讨论真实恶意敌手、腐化门槛、交互轮数、刷新和密钥一致性；算法 KeyGen、Sign、Verify 的端到端闭合优先于局部性能。
6. 以最相近正式论文和可复现传统 NTRUSolve / Threshold Falcon 等为基线，不锁死为必须优化某个既定实现。
