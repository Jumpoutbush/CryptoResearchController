# 四、全版本验收与回归矩阵

## A. 全轮次公共回归

```powershell
cd D:\CryptoResearchController
python -m unittest discover -s tests -v
.\research.cmd check all
.\research.cmd doctor --offline
git diff --check
git status --short
```

全部测试必须报告真实退出码。`check all` 在基准仓库没有个人科研目录的情况下，不能替代对用户本地项目的结构验证。Windows 的 `research.cmd` 使用实际 UTF-8 环境测试，不能仅在 Linux 模拟结果上宣称 Windows 已通过。

## C. 模块边界与发布门禁

- **v3.3：**T01—T06 全通过；使用虚拟项目验证一次自动指南修订；默认禁用时与旧版本行为一致。
- **v3.4：**T07—T09 全通过；删除索引后重建，查询结果在身份和验证等级上等价。
- **v3.5：**T10—T11 全通过；所有候选调用及失败调用有预算记录；未确认主张不升级。
- **v4.0：**T12—T14 全通过；有客观真值的评估报告、消融对照和置信区间；影子策略不能自动改科学门禁。

每个版本发布都应人工核对升级脚本没有覆盖旧项目、个人文献、研究历史和已接受报告。缺失测试、未完成原理核查或回归失败时，版本保持预发布状态。
