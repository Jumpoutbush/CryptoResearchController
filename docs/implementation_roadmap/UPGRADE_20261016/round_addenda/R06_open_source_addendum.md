# v3.4 R06 开源融合附录：科研主张与轨迹统一投影

> 这是原版 `versions/v3.4/R06_*.md` 的**补充实施规格**，原文仍是基础契约。现有代码优先，新增内容不得倒逼重做先前轮次。科学进展与开发提交分别验收。

## 一、本轮明确交付

建立只读、可重建的研究图谱投影，包含论文、命题、义务、证据、探索节点、失败分支。

## 二、对应的公开实现 / 已有代码

[ARA](https://github.com/ARA-Labs/Agent-Native-Research-Artifact)：`logic/`、`trace/exploration_tree.yaml`；现有 `engine/claim_graph.py`。外部仓库读取时核对当前许可证并固定 SHA；不得直接安装运行整个系统。

## 三、推荐修改位置（以本机已实现模块为准）

1. `knowledge/schema.py`、`knowledge/build.py` 和 claims adapter
2. `tests/test_knowledge_projection.py`

## 四、本轮实现及技术取舍

1. 优先从旧 claim/status、problem、attempt、失败路径、路线账本读取而非另写已证结论
2. 每个节点记录稳定 ID、来源文件与 SHA、冻结目标和验证等级
3. 加入 ARA 式“探索过程节点”，保存父节点与失败理由，但先只读
4. 所有派生索引是可删缓存；重建必须保证相同输入产生相同 ID 和关系
5. 非结构化历史只能标为 unverified/unmapped，不伪造精确关系

## 五、必须增加的失败测试

1. 同名 CLAIM 跨项目具有不同 ID
2. 删除图索引后重建不会修改权威主张
3. 上游未核验时派生节点不得标记 REVIEWED
4. 重复日志节点幂等去重

## 六、本轮退出条件

跨 2 个不同模拟项目建立可重建依赖与研究轨迹，并通过全量回归。

**统一禁止项**：不能改写个人项目 `GOAL.md`、研究成果状态或独立审查回执；不能默许模型把候选变已证明；不得因添加新模块重置已有科研轮次预算。每轮记录外部源码的具体上游提交、许可证、参考函数/文件、替代原理及必要适配测试。
