# v3.3 R04 开源融合附录：生成指南与原子应用

> 这是原版 `versions/v3.3/R04_*.md` 的**补充实施规格**，原文仍是基础契约。现有代码优先，新增内容不得倒逼重做先前轮次。科学进展与开发提交分别验收。

## 一、本轮明确交付

可信控制器由已验收 JSON 生成版本化指导文件，下一轮提示真实读取且不覆盖用户指南。

## 二、对应的公开实现 / 已有代码

[ARA](https://github.com/ARA-Labs/Agent-Native-Research-Artifact)：证据优先的工件结构；本地 `runner_core.build_prompt`。外部仓库读取时核对当前许可证并固定 SHA；不得直接安装运行整个系统。

## 三、推荐修改位置（以本机已实现模块为准）

1. `supervision/guide.py` 与指南 diff/rollback
2. `runner_core.build_prompt()` 的受控插入点
3. `tests/test_supervision_guide.py`

## 四、本轮实现及技术取舍

1. 从经过哈希绑定的监督建议提取核心义务、要验证的反例、下一任务和证据引用
2. 只由可信模板生成 `supervision/ACTIVE_GUIDE.md`，禁止原样拼接可执行命令或模型未审查输出
3. 目标/主张状态/安全模型更新后旧指南应显式过期，不允许继续被误读为当前权威
4. 以唯一事件 ID 和旧指南版本作比较交换；写入前确认当前文件哈希未变
5. 保留旧指南与补丁审计，无法应用时保证下一科研轮使用上一份合法指南

## 五、必须增加的失败测试

1. 断电点在 temp 写出与 atomic replace 之间，重启只能读旧或新完整指南
2. 输出带 `PROVED` 或恶意命令会被拒绝
3. GOAL/selected_idea/route_epoch 变化导致冲突，不应用过期指南
4. 下一轮 prompt 构建包含生成指南一次且权限优先级一致

## 六、本轮退出条件

R04 端到端模拟下下一轮准确注入指南；旧 `AGENTS.md` 和 `prompts/continue.md` 不受改写。

**统一禁止项**：不能改写个人项目 `GOAL.md`、研究成果状态或独立审查回执；不能默许模型把候选变已证明；不得因添加新模块重置已有科研轮次预算。每轮记录外部源码的具体上游提交、许可证、参考函数/文件、替代原理及必要适配测试。
