# v3.4 R10 开源融合附录：跨项目知识与隐私边界

> 这是原版 `versions/v3.4/R10_*.md` 的**补充实施规格**，原文仍是基础契约。现有代码优先，新增内容不得倒逼重做先前轮次。科学进展与开发提交分别验收。

## 一、本轮明确交付

实现授权跨项目只读检索，严禁把 SecAgg、Falcon、PRC 不同假设直接类比为安全等价。

## 二、对应的公开实现 / 已有代码

[ARA](https://github.com/ARA-Labs/Agent-Native-Research-Artifact)：公开工件分层；本地 source/claim 权威。外部仓库读取时核对当前许可证并固定 SHA；不得直接安装运行整个系统。

## 三、推荐修改位置（以本机已实现模块为准）

1. `knowledge/federation.py`、`knowledge/reuse_review.py`
2. `tests/test_cross_project_isolation.py`

## 四、本轮实现及技术取舍

1. 默认完全禁用；用户按项目白名单允许匿名的文献身份和精选审查结果
2. 跨项目结论必须进行域、量词、假设、敌手和泄漏函数的一一映射
3. 共享摘要由源项目冻结版本派生且脱敏，原论文私有附件、密钥和日志不可见
4. 引用的上游来源改变，目标项目只得到“旧引用过期”提醒，不自动改结果

## 五、必须增加的失败测试

1. 开启共享时也不会读取其他项目私有文件
2. 静态安全定理不能直接用于自适应腐化目标
3. 撤销共享许可后缓存中不可查询旧内容
4. 源论文变更后接收方可定位无效引用

## 六、本轮退出条件

默认禁用情况下旧项目兼容；授权后全部共享引用带完整假设映射与过期处理。

**统一禁止项**：不能改写个人项目 `GOAL.md`、研究成果状态或独立审查回执；不能默许模型把候选变已证明；不得因添加新模块重置已有科研轮次预算。每轮记录外部源码的具体上游提交、许可证、参考函数/文件、替代原理及必要适配测试。
