1. 复用 `advance_one` 的已接收回执，事件通知失败不能把合法科研轮次回滚
2. route review 与周期事件碰撞只产生一份待办；人工 STOP 优先
3. 监督失败时仅冻结监督进度，不改变研究主张或证明义务
4. 全局默认关闭，用户显式开启后才允许监督付费调用
5. 部署前以可恢复事件日志验证正常/中断/恢复路径与独立预算
