# v3.5 R11 开源融合附录：候选树与独立假设审查

> 这是原版 `versions/v3.5/R11_*.md` 的**补充实施规格**，原文仍是基础契约。现有代码优先，新增内容不得倒逼重做先前轮次。科学进展与开发提交分别验收。

## 一、本轮明确交付

引入可版本化候选分支，但保持一个冻结 GOAL 和可明确证伪的数学/密码学目标。

## 二、对应的公开实现 / 已有代码

[LLNL Co-Scientist](https://github.com/llnl/open-ai-co-scientist/blob/main/app/agents.py) 的生成/反思/去重；[AIDE](https://github.com/WecoAI/aideml/blob/main/aide/journal.py) 的树节点。外部仓库读取时核对当前许可证并固定 SHA；不得直接安装运行整个系统。

## 三、推荐修改位置（以本机已实现模块为准）

1. `candidate_search/model.py`、`candidate_search/catalog.py`
2. `tests/test_candidate_contract.py`

## 四、本轮实现及技术取舍

1. 候选包含父节点、冻结目标、精确假设、原文近邻、最小反例入口、证明义务和失败门槛
2. 对“与已有候选同义”执行去重，不能通过换名称耗费更多预算
3. 模型生成的候选仅为 PROPOSED，反思代理只给问题缺口和待检事项
4. 候选反例必须同时登记适用范围和后续允许重启条件
5. 保留已被证明直接覆盖的候选分支，防止重复提出

## 五、必须增加的失败测试

1. 减少腐化门槛伪装成原目标被拒绝
2. 重复候选反复提交不产生第二个正式预算路线
3. 上游祖先分支被淘汰不影响独立候选的有效性
4. 候选声明有未核实定理时不能标 READY_FOR_ATTEMPT

## 六、本轮退出条件

同一目标可登记三条异质、可查新、可证伪候选，任何一个都未自动升级科学等级。

**统一禁止项**：不能改写个人项目 `GOAL.md`、研究成果状态或独立审查回执；不能默许模型把候选变已证明；不得因添加新模块重置已有科研轮次预算。每轮记录外部源码的具体上游提交、许可证、参考函数/文件、替代原理及必要适配测试。
