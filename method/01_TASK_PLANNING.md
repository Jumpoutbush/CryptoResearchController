# 01. 研究决策、状态机与优先任务选择

每轮先读取 `GOAL.md`、`research/STATE.json`、`research/CLAIMS.md`、`research/FAILED_PATHS.md`、`research/BASELINES.md`、`research/GATES.json`（如存在）、最近两份报告和新增文献候选。重建以下结构，不可机械相信前次结论：

1. 冻结输入/输出/目标性质、攻击者能力、成功量化指标。
2. 主张依赖图：每个主张的前提、必需引理、证据指针、受其阻塞的阶段。
3. 已被证伪及现有工作覆盖的方案集合，标记不可无依据重复。
4. 待检任务集合：每个任务应具备证伪方法、最小成本、预期观察及判定阈值。

## 选择规则

优先级按照**可能一票否决全路线**、影响依赖图的范围、最相近成果覆盖概率、可在单轮验证、理论价值、现实成本排序。避免把“写更长的方案”“参数随机搜索”“局部工程提速”“完善措辞”排在未证安全性/正确性之前。

每轮只选一个主攻任务：
- 先说明它如何直接推进控制器固定的核心问题；上一轮 next_task 需要重新核对关联；
- 输入与前提（明确到环、维度、敌手、输出接口或具体论文定理）；
- 可测试结论（例如一个整数等式、一个安全模拟器、一个新论文包含关系）；
- 成功证据文件与失败证据文件；
- 若失败，是否直接淘汰、缩小参数、返回前置门禁，还是需要外部论文全文。

## 状态阶段建议

`INTAKE → LITERATURE → NOVELTY → FALSIFICATION → CONSTRUCTION → CORRECTNESS → SECURITY → COST → EXPERIMENT → WRITING → REVIEW`。
这是偏序，不强迫线性推进；**任意阶段遇到新反例或覆盖性论文，返回最早失效节点**。兼容旧阶段 `PROOF`、`PROTOCOL`、`BLOCKED` 等。阶段仅表明研究焦点，不等于该阶段已通过门禁。

`decision` 的语义：`CONTINUE` 继续；`PIVOT` 在相同目标下研究不同支路；`NEEDS_REVIEW` 需要用户/独立研究者决定；`PAUSE` 资源或信息暂不可得；`STOP` 有证据支持的研究终止。不要因为“当前没想法”而使用 STOP；先做有界对抗检验和查新。

## 每轮主动研究算法

读状态 → 检索近邻成果/检查新增论文 → 扫描关键障碍与约束 → 选择单项可证伪任务 → 使用推理/代码/论文原文执行 → 登记观察与反例/证明 → 评估依赖影响 → 更新下一任务和门禁。

连续两次遇到相同超时、网络阻断或空泛结果，**缩小任务颗粒度并记录根因**，不要增加模型重复次数来掩盖失败。没有可用工具时，把原本要求工具证明的主张保持为 `UNKNOWN`。

缩小任务后仍须保留与核心义务的直接关系。发现非必要的文献证明缺口时，可归档而不继续修补；边界反例应转为主构造的明确约束。细分旁支本身不构成主线进展。
