# 07. 证据台账、研究门禁与机器可检查边界

## 主张台账

在 `research/CLAIMS.md` 每条主张至少记录：唯一 ID；完整定理或性质；前提和量词；当前标签；证明依赖；原始证据路径/准确论文页码；反例状态；最新审查日期；可导致失效的变化。不得写“已证”但只有模型的自然语言判断。

## 九项门禁

- G0 范围与目标：满足 GOAL.md 冻结条件，成功指标无偷换。
- G1 查新：最近原文精读、覆盖矩阵、公开检索来源与遗漏范围。
- G2 证伪：最小反例、敌手攻击或下界检查已开展并保存。
- G3 完整正确性：闭合算法、代数和概率证明。
- G4 安全性：完整游戏/理想功能、模拟或安全归约及组合。
- G5 成本优势：同等功能的基线和完整通信/计算/轮数计费。
- G6 可复现：原始工具日志、代码、输入、配置、命令、结果保存。
- G7 论文主张：所有贡献可溯源，无虚构引文或未经证实的新颖性。
- G8 独立审查：区别来自同一模型的自审与真正独立工具/研究者审查。

`research/GATES.json` 格式示例：

```json
{
  "gates": {
    "G0": {
      "status": "INCOMPLETE",
      "evidence": [],
      "reason": "待核查与冻结目标一致性"
    }
  }
}
```

门禁取值：`INCOMPLETE`、`FAIL`、`PASS`、`CLAIMED_PASS`、`BLOCKED`。**PASS 是研究代理的证据声明，不等于控制器自动认证**。控制器仅检查指向的文件是否存在以及文件非空，不能检查定理或安全性是否真实成立。只有具体验证工具及独立复核才能提升信任级别。

## 提升与隔离

- G3、G4 未闭合时，候选不能记为端到端可用方案，不得形成安全/效率已成立的摘要贡献。
- G1 完成技术核查并确认新论文覆盖时，被影响的 CLAIM 应标记 `NOVELTY_QUARANTINED` 并回到 G1，不继续使用“首次”结论。
- G5 未成立时，不宣称系统优势，即使局部微基准改善。
- G8 不由同一模型换提示词就认定独立审稿通过。论文对外发表必须由用户授权。

在 `research/DECISION_LOG.md` 留存每次“继续/转向/终止/求助”的日期、精确证据和与上次裁决的差异。
