# 08. 论文生产、独立审查与负结果

## 何时写作

论文框架和相关工作可以随着研究积累编写，研究核心贡献必须由可核实的数学/安全/实验材料支持。论文的“已证”不得自动跟随 STATE 的阶段名。所有声称的贡献须指向 CLAIM ID 和具体证明/实验文件，参考文献须指向可核查的原始来源、版本、页码或定理位置。

## 推荐论文结构

研究动机与已有工作差异 → 形式化问题/模型 → 构造的完整算法 → 正确性与失败事件 → 安全定义和证明 → 完整成本与实验 → 局限、复现和威胁 → 参考文献。若仅得到障碍定理，则围绕“不可能性的假设边界、影响范围和严格证明”独立评价学术意义。

## 独立反驳过程

在 `research/REVIEW.md` 从四个角度提出最强反对意见：
1. 最近工作的定理/技术是否已覆盖？
2. 构造在小参数、极端输入、恶意敌手下是否失败？
3. 安全归约与分布、失败事件、组合是否存在跳步？
4. 完整成本和统计报告是否支撑所声称优势？

每条反对意见给出实验或严格反例的证据路径。单纯“再多做实验”不可代替具体失效条件。尚未解决的严重反例应导致路线淘汰、撤回/降级主张，或者返回最早失效门禁。

## 交付等级

`NOT_ESTABLISHED`：研究问题、定理、安全或新颖性未闭合；
`CONDITIONAL`：部分结果只在未证前提下成立；
`DRAFT_READY`：可形成内部论文草稿，但不代表审稿会接受；
`EXTERNAL_REVIEW_REQUIRED`：需独立审查后才能考虑投稿。

不得伪造审稿意见、会议录用信息、文献页码和实验数据。无需制造“正面结果”；合理的失败与障碍定理也应完整保存。
