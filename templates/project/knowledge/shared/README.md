# Optional public references (disabled by default)

This directory grants no sharing permission. Do not copy private PDFs, code, keys,
or logs here. An operator may prepare explicitly public `sources/` text and a
reviewed/de-identified `drafts/` summary, plus a MODEL.json bound to the existing
GOAL and problem version. The source-owner `knowledge share-preview` writes nothing.
Only a reviewed `references/` JSON whose SHA is separately approved by source and
destination controller policies can be queried across projects.

Every reference remains REFERENCE_ONLY and requires independent destination review.
Read docs/KNOWLEDGE_R10_SHARING.md in the controller for the complete schema, model
pin, revocation and public-only freshness boundary. No cache or budget is initialized.

REFERENCE_TEMPLATE.json is an intentionally incomplete PAPER_IDENTITY draft for
projects without reviewed claims. Replace every FILL value, use only public text
source hashes, and independently approve the final file in both policies. UNKNOWN
model dimensions are not equivalence. A FAILED_ROUTE_TAG uses a FAILED_BRANCH node
identity and never gains counterexample authority. The theorem-summary preview
requires an existing reviewed claim; the other two kinds do not fabricate one.
