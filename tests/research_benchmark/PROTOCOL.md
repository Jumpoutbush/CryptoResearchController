# 研究质量评估协议

cases.json 和 scripts/discovery_benchmark.py 仅检查精确整数验证器的正负样例、前提核对和有限搜索边界。平方非负是参考正确命题；程序在有限范围内没有反例，仍保持 SEARCHED_NOT_FOUND。符号错误、模等式误当整数等式、重复线性查询暴露单项是数学见证样例，不代表对 Falcon DKG 或 SecAgg 当前方案作出了完整安全裁决。

真实质量比较需另行运行三组：原阶段流程；固定单问题深度推理；深度推理加独立证伪/形式化审查。每组使用相同模型、可用原文、核心命题、调用时间及调用次数上限，保留实际 usage（若 CLI 提供）、墙钟时间、工具耗时和全部失败调用。不要把多次短调用折算为已复现某个内部模型的长时推理。

测试集分为已知正确定理（隐藏参考证明）、已知错误候选（隐藏见证）、真实开放问题（预注册量词和不可放宽条件）。同一题不同路线必须来自独立运行目录，防止答案、失败记录和已知证明泄漏；文献覆盖结论由独立审查者核对。项目数据留在本地，不提交到框架 Git。

主要指标：独立审查正确率、明确错误的检出率、对未闭合证明保持不确定状态的比例、非平凡已确认结果数、原文新颖性通过率、形式化声明对应通过率及实际计算成本。文本长度、报告数量、变量改写和工程代码量不算研究收益。预先约定失败和无进展也必须入账。

当前更新没有对开放密码学问题运行真实模型实验，没有声称提高定理发现成功率。该协议与程序回归结果应分别报告。

## v3.3 监督调度信号回放

`supervision_cases.json` 提供五个通用合成研究记录和独立的参考判定：连续无关辅助工作、改名重复证据、核心义务无进展，以及必要直接依赖、无新颖性声明的必要核心反例两个负样例。样本只使用虚构目标和收据，不载入 SecAgg、Falcon DKG、PRC 的研究结论。参考答案不传给生产检测器。

运行 `python -m unittest discover -s tests -p test_supervision_quality.py -v`，直接回放生产 `supervision_quality.assess_quality` / `from_ledger` 接口。检测依据为已验收轮次的当前主线绑定、显式工作范围、控制器主线进展信号及当轮科学证据内容哈希。重复 run 不增加计数；改名内容不构成新证据；缺少历史元数据或已截断收据保持 `INSUFFICIENT_DATA`，不从现有文件补造旧哈希。旧主线和窗口外记录不触发当前主线裁决。

这组测试验证确定性调度信号和正负样例边界，不测量真实模型识别语义偏移、生成有效任务或判断数学真假的准确率。`ON_TRACK` 只表示完整收据未命中规则，不表示证明成立；`DRIFT` 要求独立监督者根据冻结目标与证据提出具体调整，不授权改变目标、预算或证明义务。真实监督质量仍需另外保留盲测轨迹和独立专家判定。
